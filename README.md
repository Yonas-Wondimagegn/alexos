# AlexOS

Personal daily tracker PWA (study, faith, trading, workout, coding, skills). Single-file app, data stored on-device.

## Deploy on GitHub Pages
1. Create a new repo named `alexos` on GitHub (public, empty).
2. In this folder run:
   git init && git add . && git commit -m "AlexOS v1"
   git branch -M main
   git remote add origin https://github.com/Yonas-Wondimagegn/alexos.git
   git push -u origin main
3. Repo > Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
4. After about a minute open https://yonas-wondimagegn.github.io/alexos/

## Install on iPhone
Open the URL in Safari > Share > Add to Home Screen. Open it from the home-screen icon after that.

## Move data from the Claude preview
In the old page: More > Show full backup > Copy. In the new app: More > paste into the import box > Import.

## Night Gate shortcut
Shortcuts > Automation > App > (Instagram, TikTok, ...) Is Opened > Open URL: https://yonas-wondimagegn.github.io/alexos/#gate
